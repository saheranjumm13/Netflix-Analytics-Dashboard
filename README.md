# 🎬 Netflix Analytics Dashboard

An interactive Netflix Analytics Dashboard built using **Python and Streamlit** to explore Netflix movies and TV shows through data analysis and visualization.

## 📊 Project Overview

This project analyzes Netflix content to identify trends in movies and TV shows, content distribution, genres, ratings, countries, and release years.

The dashboard provides an easy-to-use interface for exploring Netflix data and viewing meaningful insights through interactive visualizations.

## ✨ Features

* 📌 Netflix content overview
* 🎬 Movies vs TV Shows analysis
* 🌍 Country-wise content analysis
* 🎭 Genre distribution
* ⭐ Rating analysis
* 📅 Release year trends
* 🔍 Interactive filters
* 📊 Data visualizations
* 🤖 Netflix prediction/model integration

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Streamlit
* Scikit-learn
* Matplotlib
* Seaborn
* Plotly

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/saheranjumm13/Netflix-Analytics-Dashboard.git
```

2. Open the project folder:

```bash
cd Netflix-Analytics-Dashboard
```

3. Install the required libraries:

```bash
pip install -r requirements.txt
```

4. Run the Streamlit application:

```bash
streamlit run app.py
```
